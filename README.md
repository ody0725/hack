# 대구대학교 2027학년도 수시모집 결과 화면 시안

## 실행
1. 이 폴더의 `index.html`을 Chrome 또는 Edge에서 엽니다.
2. 전형, 학과/학부, 수험번호, 생년월일, 지원자명, 연락처를 입력합니다.
3. `결과 보기`를 누르면 새 창에 결과 화면이 표시됩니다.

## 구현 안내
- HTML, CSS, JavaScript만 사용하는 정적 프런트엔드 시안입니다.
- 입력값은 서버로 전송되거나 저장되지 않습니다. 결과창을 열기 위해 브라우저 내부에서만 사용됩니다.
- 표시되는 `합격` 상태는 시안용 고정 문구이며 대구대학교 공식 입학 시스템의 실제 결과가 아닙니다.
- 모든 화면 오른쪽 아래에 `실제 합격 결과가 아닙니다` 안내가 고정 표시됩니다.
- 학과/전공 선택지는 대구대학교 공식 웹사이트의 공개 학과·전공 안내를 참고한 예시 목록입습니다.
